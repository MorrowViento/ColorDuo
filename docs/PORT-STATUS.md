# ColorOS 16 → 17 功能移植状态

本页记录 `fengwenhua/ColorDuo`（ColorOS 16 分支）的功能，在 ColorOS 17 分支上的对应状态。
两个分支同源于 HyperDuo `e9dffbc`，但各自改了包名与架构，**不能直接合并**，因此每项都按功能重写并单独提交 PR。

## 已移植

| 功能 | 实现 | PR | 状态 |
| --- | --- | --- | --- |
| 充电 / 快充各自一套布局 | `ChargeLayout` 编码 `1;flags;type;signal;zones`，按充电状态取用 | #1 | 已合并，真机验收通过 |
| 首次安装的可用布局 | 以「恢复推荐布局」按钮提供；默认仍为空白，避免覆盖老用户配置 | #2 | 已合并 |
| 兼容性诊断（设置侧） | 关于页复制 `key=value` 诊断块（设备、SystemUI、布局、组件、场景状态） | #3 | 已合并 |
| 兼容性诊断（适配层日志） | 首次接管后输出一行 `compat adapter=… hosts=… wifi=… mobile=…`，仅调试开关打开时 | #3 | 已合并 |
| 充电页签可逆 | 显示「自定义 / 沿用普通布局」，可一键恢复继承 | #5 | 待合并 |
| 实时 Hook 状态通道 | 有序广播 + signature 权限，第一步只回固定字符串 | #4 | 待真机验证 |

## 本分支原本就有，不属于移植缺口

| 功能 | 说明 |
| --- | --- |
| 胶囊布局 | ColorOS 17 分支已实现，待真机覆盖更多场景 |
| 环外读数（网络类型 / 信号 / 温度 / 功率） | 已实现，含串联电芯的功率归一化 |
| 字体导入 | `FontInstaller` 已实现 |
| 组件优先顺序 | 区域优先列表，非 16 分支的固定布局 |
| 配置传输与热更新 | 远程偏好 + 广播 + Bundle 传输 |

## 未移植

| 功能 | 原因 |
| --- | --- |
| 插电 / 充电弹窗期间的稳定性修复 | 16 分支基于 Find N5 的具体时序；需要在本机复现才有意义 |
| 折叠屏分阶段适配 | 本分支有 fold 相关代码，但没有真机验收记录 |
| 更新包签名校验（`UpdateManifest` / `UpdateTrust`） | 依赖 16 分支自己的发布基础设施（签名清单、公钥资产），移植等于新建一套发布流程 |

## 验证方式

- 每项移植都要求：本地 `assembleDebug` 通过、仓库离线检查通过、GitHub Actions 的 `Regression checks` 与 `Test APK` 通过。
- 涉及 SystemUI 内部状态的改动（如实时通道）额外要求真机验证，并在 PR 描述里写明排查步骤。
