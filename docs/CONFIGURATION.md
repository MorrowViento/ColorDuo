# ColorDuo 配置说明

本页适用于 ColorDuo 当前的 ColorOS 17 测试版本。安装和作用域设置见 [项目首页](../README.md)，固件与验证范围见 [适配记录](COLOROS17.md)。

## 初次设置

启用模块并重启 SystemUI 后，在绘图页选择样式、添加组件。圆环初始组件区为空，卡一和卡二的独立信号组件默认关闭；添加组件时会同时启用它需要的显示开关。

圆环的上、中、下每个区域各有一份有序列表。每帧显示列表中首个当前能够绘制的组件：闪电需要正在充电，Wi-Fi 弧需要有效信号，网络类型需要制式文字。后面的组件作为候补，同一区域每次显示一个组件。

新添加的组件会放到该区域列表的第一位，可以使用“上移”“下移”调整最终顺序。把组件移到另一区域，会从原区域移除它。

## 无 Wi-Fi 时显示网络类型

以下是一组可手动设置的圆环示例：

| 区域 | 从先到后的组件顺序 |
| --- | --- |
| 上部 | 电量数字 |
| 中部 | **Wi-Fi 弧 → 网络类型** |
| 下部 | 当前使用卡的信号点 |

把网络类型设为“环内”，确认中部列表中 Wi-Fi 在第一位、网络类型在第二位。连接 Wi-Fi 且有可绘制读数时显示弧形，断开后由网络类型接替。网络类型读取实际移动网络映射，如 5G、5GA 或 4G+。

电量数字只要有电量读数就能绘制；如果它排在网络类型前面，会优先占用该区域。可以将数字放到上部，或按需要调整候补顺序。

“预览状态 → 无 Wi-Fi”只改变模拟画面。要观察真机切换，可以断开手机的 Wi-Fi，同时保持移动网络可用。

仓库继承的 `docs/images/states.png` 来自 HyperDuo 旧版自动布局。当时断开 Wi-Fi 还会联动改变电量数字的位置。ColorDuo 当前采用区域优先列表，上表是当前配置方式；该旧图作为上游历史示意保留。

## 单卡与双卡

一组四个信号点表示一张卡的 0～4 级信号。卡一、卡二按真实卡槽分别取值，每组使用对应卡的读数。

双卡同时显示时，将“卡一信号点”和“卡二信号点”放在不同区域，例如上部与下部。把它们放入同一区域的优先列表，只会按列表选出一个组件。

环内信号点可放在上下缺口，中部用于读数。环外选择“堆叠信号”后，单卡用递增柱表示；两张卡都有读数时，另一张卡使用下方圆点。开启“仅显示上网卡”时，按实际数据卡选择读数。

## 环外组件

- 网络类型设为“环外”后，显示在电池旁。
- 信号设为“环外”且开启“堆叠信号”后，由模块绘制；关闭堆叠信号则交给系统原生图标。
- 充电功率与电池温度可分别开启；同时开启时共享位置，按两行显示。
- 环外组件的顺序、字号、字重和间距可分别调整，ColorOS 的原生布局为读数组预留空间。

功率按电池侧电流幅值乘以电压计算，会随实际充电状态和电量变化。参考固件已校正电流单位；其他固件仍需核对。充满但仍插电时可以有较小读数，拔电后功率段隐藏。它表示电池侧读数，充电器标称的最大功率属于不同测量位置。

## 预览与实际读数

设置预览共用实际绘制规则，数据使用固定示例：卡一 2 级、卡二 4 级、网络类型 5GA。“充电”“快充”“无 Wi-Fi”等是模拟场景，不会改变手机的连接或充电状态。

真机按实际电量、卡槽、信号和网络类型更新。单卡手机也可能在预览中看到双卡示例；预览点亮两个点、真机点亮四个点，本身不代表读取错误。

## 升级与生效

同签名覆盖安装会保留 ColorDuo 配置，更新 APK 后需要重启 SystemUI。日常配置修改实时生效。

alpha1/alpha2 曾额外提供初始布局；alpha3 起恢复当前继承的共享默认值。已保存的旧布局会保留，可以在绘图页重新安排。模块关闭或组件交还系统后，对应原生显示应恢复。

异常反馈请提交到 [ColorDuo Issues](https://github.com/chorusfruit-233/ColorDuo/issues)，附上组件顺序、预览场景、真机连接状态及版本信息。
